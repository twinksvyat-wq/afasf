# WHITEOUT FC

Физический файтинг 1×1 в low-poly: активный ragdoll, бесконечная белая арена, кровь, нокауты, добивания и празднования.
Ядро — **Rust без зависимостей и без движка**, оболочка iOS — **Swift + Metal + SwiftUI**.

## Запуск на iPhone (нужен Mac)

```bash
brew install xcodegen          # один раз
curl https://sh.rustup.rs -sSf | sh   # если нет Rust
cd ios && ./setup.sh           # соберёт Rust под iOS, создаст FightCore.xcframework и Xcode-проект
```
В Xcode: Signing & Capabilities → выбрать свою Team → Run на устройстве (iOS 16+). Повторные сборки пересобирают Rust автоматически (pre-build скрипт; отключить — `SKIP_RUST_BUILD=1`).

## Архитектура

```
core/                Rust-крейт fightcore (staticlib + rlib), 0 зависимостей
  src/fighter.rs     активный ragdoll: 19 частиц Верле + PBD-связи, «мышцы» тянут к позе из IK,
                     процедурные шаги, баланс, падения, подъём с колена, все удары и празднования
  src/fight.rs       мир боя: подшаги физики, капсульные столкновения тел, попадания по скорости
                     конечности, блок/парирование/контр, клинч и броски, нокдауны/KO/TKO, раунды
  src/ai.rs          ИИ: дистанция, реакции, комбо, клинч, финишеры (8 соперников, растущий скилл)
  src/render.rs      генерация low-poly сцены каждый кадр: бойцы + 76 аксессуаров, синяки, отёк,
  src/mesh.rs        кровь на лице, лужи крови на полу, тени, частицы, бесконечный пол с сеткой
  src/camera.rs      сбоку / изометрия / от третьего лица + свободный орбит, шейк, KO-слоумо
  src/profile.rs     монеты, покупки, разблокировки, статистика, сохранение
  src/lib.rs         C ABI (include/fightcore.h, module.modulemap → `import FightCore`)
  src/bin/preview.rs софтверный растеризатор (тот же шейдинг, что в Metal) для превью и CI
  tests/core.rs      стабильность физики, бои ИИ×ИИ без NaN, сохранения, совпадение ABI
  ctest/abi_test.c   проверка API со стороны C
ios/                 Swift/Metal оболочка
  Renderer.swift     один draw call, тройная буферизация, MSAA 4×, 60 FPS
  Shaders.metal      плоский low-poly свет, rim, туман в белый горизонт
  UI/TouchControls   мультитач на UIKit: плавающий стик, кнопки, свободная камера пальцем
  UI/*               меню, лестница соперников, магазин, бойцы, празднования, статистика, HUD, итоги
  Feedback.swift     хаптика и процедурный звук (без ассетов)
```

## Управление
- **Стик** — движение (вниз = апперкот / лоу-кик).
- **УДАР** — цепочка джеб → кросс → хук → апперкот; вперёд+УДАР — кросс, назад+УДАР — хук.
- **НОГА** — мидл-кик; вперёд — тип (толчок), назад — хай-кик, вблизи — колено.
- **ЗАХВАТ** — клинч; в клинче НОГА = колено, ЗАХВАТ = бросок. Жмите БЛОК/ЗАХВАТ, чтобы вырваться.
- **БЛОК** (держать) — защита; нажатый за миг до удара — парирование.
- **СУПЕР/ФИНИШ** — фирменный приём бойца; если соперник «поплыл» — гарантированное добивание.
- Палец по свободному месту экрана — вращать камеру; кнопка камеры — пресеты.
